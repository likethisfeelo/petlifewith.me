# DB 스키마 문서

스키마 원본: `data/src/db/schema.ts` (Drizzle) · 마이그레이션: `data/drizzle/`
원칙: **처음부터 최종형** (claude.md 5-5). 데이터가 비어 있어도 구조는 런칭형이다.

---

## 1. 전체 구조

```
users ─┐
       ├─ claims ──────────────┬─ spots ── spot_types / spot_links
       │                       └─ makers ── maker_links
topics ── guides ─┬─ guide_item_tags ──── items ── item_offers
                  ├─ guide_spot_tags ──── spots ── regions ── region_dog_stats
                  ├─ guide_maker_tags ─── makers ── feed_licenses
                  └─ guide_device_tags ── device_models ── device_sites
curations ── curation_entries          spots ── promotions
```

- **콘텐츠 본체**: `topics`(클러스터) → `guides`(허브 1 + 스포크 N)
- **디렉토리 병렬**: `spots`(가는 곳) / `makers`(만드는 곳)
- **개체 단위 태깅**: `guide_*_tags` 4종 — "관련 글" 수준이 아니라 오브젝트 연결.
  역방향 페이지("이 장난감이 언급된 글 N개")가 여기서 자동 생성된다.

## 2. 코드로 강제되는 규칙

| 규칙 | 강제 지점 |
|---|---|
| 의료 인접 편은 감수 전 발행 불가 | `guides` CHECK `guides_medical_review_gate` + 시드/관리자 액션 이중 차단 |
| 클레임은 스팟·메이커 중 정확히 하나 대상 | `claims` CHECK `claims_exactly_one_target` |
| 큐레이션 출처 표기(창작자명·원본 링크) | `curation_entries.creator_name / original_url` NOT NULL |
| 임베드 ref 필수 | `curation_entries` CHECK `curation_entries_embed_ref_required` |
| 이미지 재호스팅 금지 | 재호스팅용 컬럼 자체가 없음. 임베드는 공식 임베드 참조값만 저장 |
| 스팟 3곳 미만 지역 / 정보 3항목 미만 장소 noindex | `web/src/lib/seo.ts` 게이트(링크 개수 포함) + 사이트맵 쿼리 동일 기준 + 테스트 |
| 장묘·의료 인접(동물약국 등) 광고 금지 | `spot_types.monetizable=false` + 프로모션 액션에서 차단 |
| B2B 인허가(의약품 도매·의료용구 판매)는 소비자 디렉토리와 분리 | `spot_types.listed=false` — 게시는 되되(허브·지역x유형·개별 페이지 + B2B 안내문) 지역 혼합 목록·소비자 집계에서 제외 |
| 대표자 개인명·상세주소 미표시 | 해당 컬럼 없음. 주소는 ETL에서 상세부(쉼표 이후·괄호) 제거 |
| 제휴 링크 수수료 고지 | 쿠팡 선택 시 `is_affiliate` 자동 설정 → 렌더 페이지에 고지·`rel=sponsored` 자동 |
| 배지는 기준일 있는 사실 진술 | 관리자 저장 시 기준일 없으면 배지 활성화 거부 |
| 링크는 http(s) 만 | 관리자 저장 시 스킴 검증 (`isSafeHttpUrl`) |
| 미디어는 오브젝트 키만 저장 | `media_assets.object_key` + 숏코드. URL 은 렌더 시 조립 — 도메인 이전이 env 하나로 끝난다 |
| SEO 오버라이드 길이 상한 | 제목 70자·설명 200자 초과 시 저장 거부, 키 형식 검증 |

## 3. 테이블 요약

### users
내부 `id UUID` 가 PK. `cognito_sub TEXT UNIQUE NULL` 은 나중에 Cognito 연결 시 채운다 (claude.md 10-5).
지금은 인증 없이 개발 — 관리자 로그인은 토큰 방식(`web/src/lib/auth.ts`)이고 users 와 무관.

### topics / guides
- `topics.phase`: initial(노견생활·놀이) / secondary(케어·간식) / always(스팟)
- `guides.role`: hub | spoke, `spoke_group`: body(신체 영역) | support(지지 서비스)
- `guides.status`: draft → review_pending(감수 대기) → published → archived
- `medical_adjacent + vet_reviewed + vet_reviewer_name`: 감수 게이트와 "○○ 수의사 감수" 표기의 근거
- 본문 `body_md` 는 마크다운. 임베드는 `{{youtube:ID|창작자|원본URL}}` 숏코드만
  (렌더러가 창작자·원본 누락 시 렌더 거부 — `web/src/lib/markdown.ts`)
- **콘텐츠 원본은 git** (`data/content/guides/*.md`), DB는 서빙 뷰. `seed:content` 재실행 시 관리자 수정분을 덮어쓴다.

### regions / region_dog_stats
- 시군구 단위(일반구는 시로 합침). URL 슬러그는 로마자 (`seoul/gangnam-gu`).
- `region_dog_stats`: 시군구 × 출생연도 × 기준일 등록 수. **노령견 비율**은
  `web/src/lib/stats.ts` 에서 산출 — 기준: 기준일 시점 만 7세 이상(`SENIOR_AGE_YEARS=7`, 페이지에 기준 병기).

### spot_types / spots / spot_links / promotions
- 유형 시드: grooming(미용·스파), self-wash, pool, playground, boarding, visiting-bath,
  visiting-groom, rehab, transport, **memorial(장묘, monetizable=false)**,
  **pharmacy(동물약국, monetizable=false — 광고·순위 없음 + 수의사 안내문)**,
  **drug-wholesale / medical-device-shop (B2B 참고, listed=false — 소비자 목록과 분리 게시)**
- `spot_types.listed`(0003): **소비자 디렉토리 배치 여부**. false(B2B 참고) 유형도 유형 허브·
  지역x유형·개별 페이지로 게시되지만, 지역 혼합 목록·유형 분포·시도 집계에는 섞이지 않는다.
  전 페이지에 B2B 안내문이 자동으로 붙고 광고 불가(monetizable=false)다.
- `spots.source`: public_data(인허가 시딩) / direct(직접 발굴 — 독점 자산) / claimed / sample(로컬 픽스처, 색인·사이트맵 제외)
- 인허가 원천 필드(name, address_road, status, license_*, data_reference_date, raw_coord_*)는 ETL이 upsert.
  **에디토리얼 필드(description_md, hours_text, price_text, …)와 type_id 재분류는 ETL이 덮어쓰지 않는다.**
- `spot_links`: 홈페이지·카카오톡·예약·네이버·인스타 등 **선택적 링크**. 고정 컬럼 대신 목록으로 두는 이유는
  업체마다 쓰는 채널이 제각각이고, 채널이 늘 때마다 스키마를 바꾸지 않기 위해서다 (`maker_links` 와 동일 구조).
  링크 개수는 noindex 게이트의 "정보 항목" 수에 포함된다.
- `raw_coord_x/y/system`: 인허가 좌표는 좌표계 확인 전까지 원본 보관만. lat/lng 변환은 좌표계 확정 후.
- `data_reference_date`: 페이지에 "인허가 데이터 기준일"로 표기 (리스크 대응).
- `promotions`: 노출 광고 슬롯(region_top / content_card). 가격은 트래픽 확보 후 책정 — 지금은 구조만.

### makers / maker_links / feed_licenses
- 지역은 `region_id`(시군구)까지만. 상세주소·대표자명 컬럼 없음.
- 배지: `badge_feed_registered`(사료제조업 등록 확인), `badge_ingredient_registered`(성분등록 확인).
  "인증" 아님 — 공적 데이터 기반 **사실 진술**. `badge_verified_at`(기준일) + `badge_note` 를 툴팁에 표기.
- `feed_licenses`: 사료제조업 인허가 원장(ETL 적재). `makers.feed_license_id` 로 근거 연결.
- `selection_memo`: 선정 기준(기획서 4-4) 검증 내부 메모 — 렌더링 금지.

### items / item_offers
- `item_offers.is_affiliate=true` 링크가 렌더되는 모든 페이지에 수수료 고지가 자동 노출
  (컴포넌트 `AffiliateDisclosure`, 본문 내 쿠팡 링크는 렌더러가 감지).
- 상품 페이지는 역참조(언급 글 목록)가 본질 — 언급 발행 글이 0이면 noindex.

### device_models / device_sites
- 치료·진단 기기: **주어는 병원이 아니라 기기**. 원리·스펙 서술, 효과 단정 금지(에디토리얼 규칙).
- `device_sites`(보유처)는 기기 콘텐츠 안에서만 무료 노출. 별도 디렉토리 페이지·광고 상품 없음. 가나다순, 순위 없음.

### curations / curation_entries
- 큐레이션은 **테마 단위**만 (`/curation/[theme]`). 크리에이터 개인 허브 없음.
- entries: 공식 임베드(youtube videoId / instagram 게시물 URL) 또는 링크 전용(none) + 우리 언어 요약(NOT NULL).

### claims
- 스팟·메이커 소유 확인 접수. `contact`, `biz_registration_no` 는 관리자 확인 전용 — 어디에도 렌더하지 않는다.

### media_assets
- 직접 촬영·제작한 이미지·영상의 원장. `object_key` 만 저장 — URL 은 렌더 시
  `NEXT_PUBLIC_ASSET_BASE_URL` 로 조립한다 (claude.md 10-1). 업로드는 presigned PUT.
- 본문 삽입은 숏코드 `{{image:키|alt|캡션}}` / `{{video:키|캡션}}` 로만 한다.

### 페이지별 SEO 오버라이드 컬럼
- `guides / curations / spots / makers / items` 공통: `seo_title`, `seo_description`, `og_image_key` (전부 NULL 허용)
- 대표 이미지: `guides.hero_image_key`, `spots.hero_image_key`, `makers.hero_image_key`, `items.image_key`
- 렌더 우선순위: 오버라이드 → 대표 이미지 → 사이트 기본 OG 이미지 → 없음

## 4. 문서화된 가정 (검증 필요 항목)

- **노령견 기준 7세**: 통용 기준(7~8세)의 하한 채택. 페이지에 기준 병기. 상수 한 곳(`SENIOR_AGE_YEARS`)에서 변경 가능.
- **지역 로마자 슬러그**: 통용 표기 기반. 식별자일 뿐이므로 런칭 전 표기 검수만 하면 됨. ETL은 목록 밖 시군구를 만나면 적재하지 않고 리포트에 남긴다.
- **인허가 CSV 컬럼**: `data/src/etl/license/mappings.ts` 의 후보 헤더로 해석. 필수 컬럼 미발견 시 즉시 실패(추측 금지).
- **인허가 좌표계**: 미확정 → 원본만 저장. 확정 후 변환 단계 추가.
- **영업상태 문자열 매핑**: 폐업·취소·말소·정지·중지·폐쇄 → closed / 휴업 → suspended / 영업·정상·운영 → operating. 미매핑 값은 unknown 으로 적재 + 리포트.
