스팟 — 전체 너비 + 오른쪽 미리보기

카드를 눌러 보세요. PC는 오른쪽에서 미리보기 창이 열리고, 모바일은 아래에서 시트가 올라와요.

제안 요약
  • 너비 — 다른 메뉴는 지금처럼 가운데 1100px, 스팟 목록 화면만 화면 전체 너비. 왼쪽 필터 고정 + 가운데 카드는 화면 폭만큼 자동으로 3~6열
  • PC 미리보기 — 넓은 화면(1280px 이상)은 목록을 밀어내고 오른쪽 420px 칸에 미리보기(목록이 그대로 보여 다른 업체로 바로 넘어가기 쉬움). 그보다 좁으면 목록 위를 덮는 슬라이드 창 + 어두운 배경
  • 모바일 — 아래에서 올라오는 시트(화면 60%). 위로 끌거나 "크게 보기"를 누르면 전체 화면, 뒤로 가기·아래로 끌면 닫힘
  • 미리보기 내용 — 링크 페이지의 요약(사진·기본 정보·채널 버튼·상담 버튼·지도 작게) + "전체 페이지 보기"
  • SEO·공유 — 카드는 진짜 링크(/place/…)로 두고, 누를 때만 미리보기로 가로챔. 주소창도 그 업체 주소로 바뀌어 새로고침·공유하면 전체 페이지가 열림 (Next.js의 '가로채는 경로' 기능)
