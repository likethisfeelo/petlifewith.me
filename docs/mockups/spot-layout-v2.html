예시 사이트에서 가져올 것 / 바꿀 것 / 빼는 것
  • 가져올 것 — 왼쪽 필터 패널, 위쪽 유형 탭(아이콘), "1–24 / 1,240곳" 결과 줄, 카드·목록·지도 보기 전환, 목록+지도 나란히 보기, 카드 아래 "유형 › 지역" 줄
  • 바꿀 것 — 가격·할인 배지 → 우리 데이터에 있는 운영시간·주차·요금 안내 태그로. 큰 사진 칸 → 사진 없는 곳이 대부분이라 유형 아이콘 + 색을 기본으로, 사진은 있을 때만. 파란 체크 → "사장님 관리 중"(소유 연결된 곳). 모서리 ★ 표시 → 지역 상단 노출(유료)을 "광고"로 표기
  • 빼는 것 — 별점·평점(순위·평점 구조를 만들지 않는 원칙), 카드 아래 접기 화살표(의미 불분명), "Black Friday" 같은 홍보 카테고리
  • SEO 원칙 — 필터를 바꾸면 쿼리스트링이 아니라 기존 SEO 주소(/spot/서울/강남구/미용)로 이동. 색인 페이지는 그대로 두고 화면만 탐색형으로
① 탐색형 — 지역·유형 페이지를 "필터 + 카드 목록" 한 화면으로 합칩니다. 지금 지역 페이지의 지도 타일은 왼쪽 필터의 "지역" 안으로 들어가요.
