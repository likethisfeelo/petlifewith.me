## 0. 한 장 요약

**펫라이프위드미(pet life with me)** — "반려동물의 행복한 삶, 나와 함께"

> 반려동물이 **무엇을 즐거워하고, 나이 들어 무엇이 필요한지**를 다루는 콘텐츠 미디어다.
> 글에서 시작해 그 글에 나온 **장소·브랜드·상품·도구·사람(돌봄 파트너·훈련사)** 으로 이어진다.

### 이 서비스가 **아닌** 것 (인스타에서 오해받기 쉬운 지점)

| 흔한 오해 | 실제 |
|---|---|
| "애견동반 카페·펜션 찾는 앱이구나" | 동반 가능 장소는 **다루지 않는다.** 축은 "어디에 데려갈 수 있나"가 아니라 "무엇이 즐거운가"다. |
| "업체 목록 사이트(디렉토리)구나" | 본체는 **콘텐츠(글·영상)** 다. 디렉토리는 글에 등장한 것을 찾아가는 **병렬 장치**다. |
| "동물병원 추천해 주는 곳이구나" | 병원 디렉토리·순위·평점을 **만들지 않는다.** 병원은 장비 보유처로만, 무료·가나다순으로 나온다. |
| "광고 받고 업체 띄워 주는 곳이구나" | 유료 노출은 **"광고" 라벨이 붙은 지역 상단 슬롯 하나**뿐. 장묘·약국·병원·돌봄 파트너는 유료 노출 대상이 아니다. |
| "수의사 상담 서비스구나" | 상담은 **훈련사·멘토의 생활 상담**만. 진단·처방·치료는 다루지 않는다. |
| "커뮤니티 앱이구나" | 커뮤니티(게시판·모임)는 있지만, 운영진이 고른 **큐레이션 콘텐츠**가 중심이고 회원 글은 승인 후 공개된다. |

### 한 문장 포지셔닝 (채널 소개용 후보)

- "노견의 하루와 반려견의 놀이를 정리하는 곳 — 그리고 그걸 도와줄 곳까지."
- "검색하면 흩어져 있던 노견·놀이 정보를, 한 곳에서 이어서 봅니다."

### 2-2. 콘텐츠 미디어 (본체)

**노견생활** — 초반 핵심 클러스터
- 상단 **SVG 신체 지도**: 부위를 누르면 "집에서 살펴보는 관찰 포인트" Q&A와 관련 글이 뜬다.
- 콘텐츠 구조는 보호자가 **변화를 느낀 순간**에서 출발한다:
  `변화를 느낀 순간 → 무엇을 살펴볼까 → 확인하는 방법 → 도울 수 있는 것 → 일상을 편하게`
- 허브 1편 + 신체 영역 스포크 + 지지 서비스 스포크(방문목욕·재활·방문미용·데이케어·마지막 시간).
- 하단 **돌봄 배너**: "직접 방문(유치원·데이케어·시간제 시터) / 집으로 오는(펫시터·산책)" 으로 디렉토리 연결.
- 의료 인접 글은 **수의사 감수 전 발행 불가**(시드·관리자·DB 3중으로 막힘), 감수 배지 표시.
- 콘텐츠 현황(시드 기준): 노견 13편(발행·감수 대기·초안 혼재) + 놀이 5편.

**놀이** — 가볍고 전환이 빠른 클러스터
- 운영진·회원 글 전체를 **영상 카드**로 보여 준다(섬네일 + 마우스 올리면 미리보기).
- 글에 태그된 상품·브랜드가 우측 패널에 붙는다.
- 놀이 영역에서는 태그라인이 "반려동물의 **즐거운** 삶, 나와 함께"로 바뀐다.

**게시판 3분할**
| 구분 | 누가 채우나 | 노출 |
|---|---|---|
| 큐레이션 콘텐츠 | 운영진 발행 + 회원 글 중 운영진 선정 | 토픽 상단 9편(순번 1~9) → 전체 보기 |
| 일반 게시판 | 회원 | 승인 후 공개, 최신순 |
| 부위별 게시판 | 회원·운영진 (부위 지정 글) | 부위 대표 1~3 + 목록 |

**글 상세에서 일어나는 일**
- 글 속 개체(상품·브랜드·장소·기기)에 **직접 태그** → 옆 패널에서 바로 이동. 태그가 쌓이면 "이 상품이 언급된 글 N개" 역방향 페이지가 자동으로 생긴다.
- 표기 자동화: 수의사 감수 배지 / "광고 · ○○ 협찬" / 쿠팡 파트너스 수수료 고지 / "진료를 대체하지 않습니다" / 회원 글 안내.
- 좋아요(수 공개)·저장(본인만)·댓글.

**크리에이터 큐레이션** — 테마 단위(크리에이터 개인 페이지는 만들지 않는다). 유튜브·인스타 **공식 임베드만**, 이미지 재호스팅·자막 복사 금지. 첫 테마 준비 중.

### 2-3. 디렉토리 (병렬)

**스팟 디렉토리** — `/spot` → 시도 → 시군구 → 유형
- 좌측 시도→시군구 **타일 지도**, 우측 목록. 지역 페이지마다 고유 데이터 블록(스팟 밀도·유형 분포·노령견 비율).
- 데이터: 행정안전부 인허가 공공데이터 + 직접 발굴. 모든 장소에 **출처·기준일·관리번호** 표기.
  - 적재 완료(2026-08): 동물미용업 16,107 / 동물운송업 4,643 / 동물약국 20,796 / 의약품 도매·의료용구 판매 4,661(B2B, 비공개 집계용)
  - 직접 발굴: 미용·출장목욕·셀프목욕·호텔 48곳, 재활·한방·특수치료 123곳
- 유형: 미용·셀프목욕·수영장·놀이터·카페·위탁·방문목욕·방문미용·운동·재활·운송 (유료 노출 가능) / **장묘·약국 (광고·순위 없음, 가나다순)**
- 얇은 페이지 방지: 스팟 3곳 미만 지역, 정보 3항목 미만 장소는 검색 비노출(noindex).

**개별 장소** `/place/[id]`
- 운영시간·요금·주차·연락 링크(카카오톡·홈페이지·예약·네이버·인스타), 저장.
- "이 장소가 등장한 이야기"(글 역참조).
- 영업 중이고 유료 가능 유형이면 **예약·상담 신청** 버튼.
- 업주용: "정보 관리 요청(무료)", "지역 상단 노출 신청(유료)", 정정 신고.

**돌봄 파트너** — 펫시터(보호자 집 방문) / 시간제 시터(시터 집에 맡김) / 펫산책
- 주소 대신 **활동 지역**으로 노출. 시군구 × 유형마다 **5자리** — 빈 자리는 "비어있습니다"로 보인다.
- 순위·평점 없음, 유료 노출 대상 아님. 카드에서 예약 신청·카카오톡 상담.
- 현재 가상 "예시" 2건만 있음 → **실제 파트너 모집이 필요한 영역.**

**운동·재활·한방** `/rehab` — 치료법이 주어
- 침·한방·재활·수중런닝·도수·체외충격파·고압산소·레이저·대학병원 등 치료법별 시행처 목록.
- 지역별 가나다순, 순위·평점·광고 없음, "병원 추천 아님" 고지.

**관리·재활 도구** `/device` — 기기가 주어
- 기기 → 본사 → 대리점 → **지역별 체험 가능 업체** → 보유 병원(무료·순위 없음) → 다룬 글.
- "주목 기기" 슬롯과 협찬 글은 광고 표기와 함께 노출.

**메이커·상품**
- 메이커: 직접 제조하는 브랜드만. "사료제조업 등록 확인", "성분등록 확인" **사실 배지**(기준일 표기). 대표자 개인명·상세 주소는 표시하지 않는다.
- 상품: 구매 링크(쿠팡 파트너스·자사몰) + 언급된 글. 1차 발굴(간식 10 + 장난감·용품 10) 준비 중.

### 2-4. 사람과 연결되는 서비스

**노견 생활 상담** `/consult` (헤더 메뉴)
- **훈련사·멘토**만. 회원이 `/me/expert` 에서 직접 프로필을 만든다(멘토 즉시 공개, 훈련사는 자격 확인 후).
- 활동 지역(최대 5곳)으로 지역 지도에 노출, 온라인 전용도 가능.
- **바로 채팅(시범)**: 회원이면 결제 없이 대화 시작(하루 10건). 시간 예약·유료 상담은 예약 흐름으로.
- 진단·처방·치료를 다루지 않는다는 안내가 대화방에 자동으로 들어간다.

**펫모임** `/meetup`
- 회원이 내 지역(시군구 최대 3곳)을 골라 그 지역 모임에 참여하거나 직접 만든다(승인 없음).
- 비회원에게는 "모임 n개 · m명 참여 중" 집계만 보이고, 모임 게시판은 참여자만.
- 장소는 짧은 문구만(주소 금지).

**예약·채팅**
- 업체·돌봄 파트너·전문가에게 요청 → 제공자(소유 회원·전문가) 또는 운영자가 확인 → **결제 확인은 수동**(계좌·결제 링크 안내 후 확인) → 채팅방 열림 → 완료.
- 카드 결제(PG)는 아직 없다.

### 3-3. 회원 참여의 규칙 (인스타에서 그대로 안내해도 되는 것)

- **회원 글은 운영진 확인 후 공개**(기본 켬). 공개 글을 고치면 다시 확인을 거친다.
- **댓글은 바로 공개**, 규칙 위반은 사후 숨김.
- 진단·처방 단정, 병원·상품 광고 글은 승인되지 않는다.
- 유튜브·인스타 임베드는 창작자명·원본 링크 필수. 영상은 업로드 시 길이 상한(기본 3분) 안으로 자동으로 잘린다.
- 운영진이 일반 게시판의 회원 글 중 대표 글을 **큐레이션으로 골라 위에 세운다** → "내 글이 큐레이션에 오른다"가 참여 동기가 된다.

### 3-4. 사장님(업체·브랜드) 참여 흐름

```
요청함 (로그인 없이)                              운영자                    사장님
업체 등록 / 정보 관리 요청  ─→ 슬랙 알림 ─→  확인·스팟 연결  ─→  "소유자 연결"  ─→  /me/business
                                                                                    운영시간·요금·소개·사진·링크
지역 상단 노출 (A·B·C형)   ─→ 슬랙 알림 ─→  결제 안내 → 입금 확인 → 노출 ON          상품(자사몰 링크)
```
- 이름·주소·유형·지역은 요청으로만 바뀐다. 쿠팡 제휴 링크는 운영자만 붙인다.
- 기본 등록·정보 관리는 **무료**. 유료는 지역 상단 노출 하나(가격은 아직 미정 — "요청 후 안내").

## 4. 운영(관리자) 형태

### 4-1. 운영 조직과 알림

- 관리자 화면 `admin.petlifewith.me`, 사람별 토큰·라벨로 계정 구분(회수 즉시 세션 종료).
- **슬랙으로 오는 것**: 요청함 접수, 예약 신청, 새 펫모임, 바로 채팅 시작.
- **슬랙으로 안 오는 것(직접 확인)**: 회원 새 글 승인 대기, 댓글, 훈련사 프로필 → 대시보드 카운트로 확인.

### 4-3. 운영 원칙 = 신뢰 장치 (채널에서 차별점으로 쓸 수 있는 것)

1. **병원 순위·추천 없음.** 병원은 장비 보유처로만, 무료·가나다순.
2. **의료 인접 글은 수의사 감수 후에만 공개**, "진료를 대체하지 않습니다" 고지.
3. **장묘·약국은 광고·순위 없음.** 급한 순간에 검색하는 영역이라 사실 정보만.
4. **광고는 반드시 표기.** 지역 상단 노출 "광고", 협찬 글 "광고 · ○○ 협찬", 쿠팡 파트너스 수수료 고지.
5. **출처·기준일 명시.** 모든 장소에 공공데이터 출처·기준일·관리번호.
6. **크리에이터 콘텐츠는 공식 임베드 + 출처 표기만.** 이미지 퍼오기·재업로드 금지.
7. **배지는 사실만.** "인증"이 아니라 "사료제조업 등록 확인"처럼 확인한 사실과 기준일.
8. **개인정보 보호.** 1인 브랜드·돌봄 파트너의 대표자명·상세 주소 비공개, 모임 장소도 주소 금지.

### 6-1. 시장 배경

- 반려가구 **591만 가구(전체 가구의 26.7%)**, 반려인 1,546만 명 (2024년 말, KB경영연구소 「2025 한국 반려동물 보고서」).

- 노령견 비중: 국내 등록 반려견 중 9세 이상이 약 41%라는 인용이 있다(기준·출처별 편차 있음 — 사이트의 지역별 노령견 비율은 농림축산검역본부 동물등록 통계로 직접 산출 예정).
- KB 보고서는 4세 무렵부터 치료비가 오르기 시작해 **7세 이후 증가폭이 커진다**고 정리한다.

→ "**지금 키우는 아이가 나이 들어 간다**"는 보호자가 가장 크고 빠르게 늘어나는 층이다. 노견생활을 첫 클러스터로 둔 이유와 같다.

### 6-2. 핵심 세그먼트

**A. 노견 보호자 — "변화를 느낀 사람"** (1순위)
- 누구: 7세 이상 반려견과 사는 30~50대. 10년 가까이 함께 산 아이라 정서적 몰입이 깊다.
- 들어오는 순간: 계단을 안 올라간다 / 산책 거리가 줄었다 / 밤에 서성인다 / 목욕시키기가 힘들어졌다.
- 지금의 불편: 블로그·유튜브에 정보가 흩어져 있고, 병원 광고와 섞여 무엇을 믿을지 모른다.
- 우리가 주는 것: 신체 지도 → 부위별 관찰 포인트 → 감수 글 → 재활·한방·관리 도구 → 방문목욕·방문미용·돌봄 파트너 → 노견 생활 상담 → 같은 고민의 보호자 게시판.
- 인스타 반응 포인트: "우리 애도 이래요" 공감형 카드, 체크리스트 저장, 노견 일상 사진.

**B. 놀이·일상 콘텐츠를 즐기는 보호자 — "더 재미있게 해 주고 싶은 사람"** (1순위, 유입량 담당)
- 누구: 1~7세 반려견 보호자, 20~30대 비중 높음. 인스타·릴스 소비가 가장 활발.
- 들어오는 순간: 실내에서 뭘 하고 놀지 / 노즈워크 장난감 뭐 사지 / 비 오는 날 에너지 발산.
- 우리가 주는 것: 놀이 영상 피드, 장난감·간식 브랜드와 구매 링크, 수영장·놀이터·셀프목욕 스팟, 영상 올리기.
- 인스타 반응 포인트: 짧은 놀이 릴스, "따라 해 보세요", 사용자 영상 리그램(동의·출처 표기).

**C. 돌봄이 필요한 보호자 — "자리를 비워야 하는 사람"** (2순위, 전환형)
- 누구: 맞벌이·1인 가구, 출장·여행, 노견을 혼자 두기 어려운 보호자.
- 우리가 주는 것: 펫시터·시간제 시터·산책 파트너(지역 5자리), 데이케어·유치원, 예약 신청·채팅.
- 인스타 반응 포인트: "데이케어 vs 펫시터 뭐가 맞나" 비교 카드, 지역별 파트너 소개.

**D. 공급자 — 업체·브랜드·돌봄 파트너·훈련사** (2순위, B2B)
- 누구: 미용·셀프목욕·수영장·재활 업주, 수제간식·장난감 1인 브랜드, 펫시터·도그워커, 훈련사.
- 지금의 불편: 플랫폼 수수료·입찰 광고에 지친다. 작은 브랜드는 쿠팡 상위에 안 잡힌다.
- 우리가 주는 것: **무료 등록·정보 관리**, 글 속 태깅으로 자연스러운 노출, 사실 배지, 지역 상단 노출(소수 슬롯), 상담 프로필.
- 인스타 반응 포인트: "이 브랜드를 고른 이유" 소개 콘텐츠 + 태그 → 브랜드가 리그램(백링크·신뢰).

**E. 크리에이터** (협업 대상)
- 반려동물 유튜버·인스타그래머. 테마 큐레이션에 공식 임베드로 소개하고 "이렇게 소개했습니다" 안내 → 공유·협업으로 이어진다.

### 6-3. 세그먼트별 진입 → 전환 경로

| 세그먼트 | 인스타 첫 접점 | 사이트 착지 페이지 | 원하는 다음 행동 |
|---|---|---|---|
| A 노견 보호자 | 노견 변화 체크리스트 카드 | `/topic/senior-life` (신체 지도) | 부위별 글 읽기 → 저장 → 게시판 글쓰기 |
| B 놀이 보호자 | 놀이 릴스 | `/topic/play` | 영상 피드 → 장난감·브랜드 → 영상 올리기 |
| C 돌봄 필요 | 돌봄 비교 카드 | `/spot/type/pet-sitter` 등 | 지역 선택 → 예약 신청 |
| D 공급자 | "등록은 무료" 안내 / 브랜드 소개 | `service.petlifewith.me` | 업체 등록·정보 관리 요청 |
| E 크리에이터 | 큐레이션 소개 + 태그 | `/curation/[테마]` | 공유·협업 문의 |

## 7. 인스타그램 채널 기획

### 7-1. 채널 목표

1. **오해 없이 정체성을 전달한다** — "동반 장소 앱"이나 "병원 추천"이 아니라 "노견과 놀이를 정리하는 곳"으로 기억되게.
2. **사이트로 보낸다** — 인스타는 요약·공감, 사이트는 전체 정보·연결.
3. **참여자를 모은다** — 회원 글·영상, 돌봄 파트너, 업체·브랜드 등록.

### 7-2. 계정 구성

- **계정 1개로 시작**(노견 + 놀이 함께). 사이트가 두 클러스터를 같이 미는 이유와 같다 — 톤이 균형을 잡고 노견 보호자가 놀이로, 놀이 보호자가 미래의 노견 정보로 이동한다.
- 공급자 대상 안내는 별도 계정 없이 하이라이트로 분리.

**프로필 문구(예시)**
```
펫라이프위드미 | pet life with me
노견의 하루, 반려견의 놀이를 정리합니다
병원 순위·광고 없는 정보 · 수의사 감수 표기
🔗 petlifewith.me
```

**하이라이트**
| 하이라이트 | 내용 |
|---|---|
| 처음이라면 | 이 계정·사이트가 무엇이고 무엇이 아닌지 (0장 표를 카드로) |
| 노견 체크 | 부위별 관찰 포인트 카드 모음 |
| 놀이 | 놀이 릴스 모음 |
| 돌봄 | 펫시터·시간제 시터·산책·데이케어 차이와 찾는 법 |
| 함께 써요 | 회원 글·영상 올리는 법, 큐레이션 선정 사례 |
| 사장님 | 업체·브랜드 무료 등록, 정보 관리, 상단 노출 안내 |
| 원칙 | 광고 표기·감수·출처·병원 순위 없음 |

### 7-3. 콘텐츠 기둥 (비율은 시작 제안값)

| 기둥 | 비율 | 형식 | 예시 |
|---|---|---|---|
| ① 노견 변화 신호 | 30% | 캐러셀 6~8장 | "계단을 안 올라가요 — 집에서 살펴볼 4가지" (신체 지도 부위별 연재: 관절·심장·인지·눈귀·치아·체중·피부·뒷다리) |
| ② 놀이 | 30% | 릴스 15~30초 | 노즈워크·실내놀이·저강도 놀이(노견용) — 노견과 놀이가 만나는 지점 |
| ③ 연결 정보 | 15% | 캐러셀 | "방문목욕이 맞는 경우", "데이케어 vs 펫시터", "수중런닝은 어디서 해 볼 수 있나" (재활 치료법·도구 페이지로) |
| ④ 사람·브랜드 | 15% | 캐러셀·릴스 | 회원 글 큐레이션 선정, 발굴 브랜드 "고른 이유", 돌봄 파트너·훈련사 소개 |
| ⑤ 원칙·서비스 안내 | 10% | 단일 카드·스토리 | "왜 병원 순위를 안 만드나", "광고는 이렇게 표기합니다", 사장님 무료 등록 |

**오해 방지 장치**
- 업체·브랜드가 나오는 게시물은 협찬이면 반드시 "광고 · ○○ 협찬" 표기, 아니면 "협찬 없음" 명시.
- 의료 인접 주제는 캡션 끝에 "진료를 대체하지 않습니다. 이상 신호는 병원으로." 고정 문구.
- 병원 이름을 띄우는 게시물은 만들지 않는다. 장비·치료법이 주어.

### 7-4. 발행 리듬 (시작 제안)

- 피드: 주 3~4회 (노견 캐러셀 1~2 + 놀이 릴스 1~2 + 기타 1)
- 스토리: 주 3~5회 (사이트 신규 글 링크, 질문 스티커 "우리 아이는?", 투표)
- 사이트 발행과 연동: 큐레이션 콘텐츠 1편 발행 → 인스타 요약 캐러셀 1개 → 링크 스티커.

### 7-5. 사이트 연결 동선

- 프로필 링크는 홈 하나보다 **목적별 링크**가 맞다:
  노견 → `/topic/senior-life` / 놀이 → `/topic/play` / 돌봄 찾기 → `/spot/type/pet-sitter` / 사장님 → `service.petlifewith.me`
- 게시물마다 해당 글로 가는 링크(스토리 링크 스티커, 캡션 "프로필 링크 → 노견").
- 사이트 OG 이미지(글 대표 이미지)를 인스타 카드 디자인과 맞추면 공유 시에도 같은 브랜드로 보인다.

### 7-6. 참여·모객 캠페인 아이디어

| 캠페인 | 대상 | 방식 | 사이트 연결 |
|---|---|---|---|
| "우리 노견의 하루" | A | 노견 일상 사진·영상 사연 모집 → 대표작 소개 | 일반 게시판 글쓰기 → 큐레이션 선정 |
| "놀이 따라 하기" | B | 놀이 릴스 따라 찍기 해시태그 | 놀이 피드에 영상 올리기 |
| "부위별 체크 연재" | A | 8주간 부위 1개씩 | 부위별 게시판 질문 |
| "우리 동네 돌봄 자리" | C·D | "○○구 펫시터 자리 비어 있어요" | 돌봄 파트너 등록 / 예약 |
| "고른 이유" | D | 발굴 브랜드 소개 + 브랜드 태그 | 메이커 페이지 → 정보 관리 요청 |
| "크리에이터 테마 큐레이션" | E | 테마 공개 + 창작자 태그 | `/curation/[테마]` |

### 7-7. 지표 (KPI)

| 단계 | 지표 |
|---|---|
| 인지 | 도달, 팔로워 증가, 저장 수(캐러셀은 저장이 핵심) |
| 유입 | 프로필 링크·스토리 링크 클릭 → 사이트 세션(GA4에서 utm 구분: `utm_source=instagram`) |
| 참여 | 회원 가입, 회원 글·영상 수, 댓글, 펫모임 개설 |
| 공급 | 요청함 접수(업체 등록·정보 관리·돌봄 파트너), 상담 프로필 등록 |
| 전환 | 예약 신청, 쿠팡 파트너스 클릭 |

### 7-8. 채널 운영 규칙 (사이트 원칙과 동일)

- 타인의 사진·영상을 내려받아 올리지 않는다. 리그램은 **본인 동의 + 계정 태그** 필수.
- 협찬·제휴는 **표시광고법**에 맞춰 첫 줄 또는 이미지 안에 표기.
- 효과 단정 금지("관절염에 효과" ✕ → "○○ 목적으로 사용된다" ○).
- 장묘·이별 콘텐츠는 홍보·광고와 섞지 않는다.

## 8. 채널 시작 전 확인할 것

### 8-1. 사이트 쪽에서 먼저 채우면 좋은 것 (인스타로 보냈을 때 빈 페이지 방지)

| 항목 | 현재 | 필요 |
|---|---|---|
| 노견 초안 스포크 (심장·인지·눈귀·치아·체중·마지막 시간) | 초안·감수 대기 | 감수 후 발행 |
| 놀이 콘텐츠 | 5편 | 릴스 연재와 맞춰 확충 |
| 크리에이터 큐레이션 | 준비 중 | 첫 테마 1개 |
| 메이커·상품 | 준비 중 | 1차 발굴(간식 10 + 장난감·용품 10) |
| 돌봄 파트너 | 예시 2건 | 실제 파트너 모집 (캠페인과 동시) |
| 지역 상단 노출 A·B·C형 | 가격·안내문 비어 있음 | 사장님 하이라이트 전에 확정 |
| 노령견 비율(지역 데이터) | 통계 미적재 | 동물등록 통계 적재 |
| 쿠팡 파트너스 | 고지 자동화만 | 실링크 연동 |

### 8-2. 사용 흐름에서 보완하면 좋은 것

- 회원 **비밀번호 찾기·이메일 인증·탈퇴** 없음 → 인스타로 가입자가 늘기 전에 필요.
- 회원·제공자 **알림(이메일·카카오 알림톡)** 없음 → 예약 받은 사장님이 놓칠 수 있다.
- **카카오 로그인** 없음 → 국내 모바일 유입(인스타 → 사이트)에서 가입 이탈 요인.
- 회원 새 글은 슬랙 알림이 없어 승인이 늦어질 수 있다 → 캠페인 기간에는 확인 주기를 정한다.
- 결제는 수동(PG 없음) → 예약·유료 상담 캠페인은 규모를 작게.
- `product.` 제품 사장님 포털은 안내·메일 링크만 있고 신청 폼이 없다.

### 8-3. 결정할 것

1. 계정명(핸들)과 프로필 문구
2. 계정 하나로 갈지, 노견 / 놀이 분리할지 (권장: 하나로 시작)
3. 콘텐츠 제작 리소스 — 주 3~4회 피드를 누가 만드나
4. 첫 캠페인 — "우리 노견의 하루" vs "놀이 따라 하기"
5. 지역 상단 노출 가격 공개 여부와 시점
